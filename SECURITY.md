# Security Policy

## Supported Versions

This project is under active development. Security fixes are applied to the latest code on the `main` branch. Older commits and unofficial forks are not supported.

## Reporting a Vulnerability

Please do **not** disclose a suspected vulnerability in a public issue, discussion, or pull request.

Use GitHub's private vulnerability reporting option under the repository's **Security** tab if it is available. Otherwise, contact the maintainer privately using the contact options on the [maintainer's GitHub profile](https://github.com/krutharth-dev) before sharing technical details.

Include, where possible:

- A clear description of the vulnerability and its impact
- The affected component, version, branch, or commit
- Reproduction steps or a minimal proof of concept
- Relevant logs or screenshots with secrets and personal data removed
- Any suggested mitigation

The maintainer aims to acknowledge a complete report within seven days, investigate it, and coordinate a fix and responsible disclosure timeline where appropriate.

## Security Considerations

Never commit credentials, Wi-Fi passwords, broker credentials, API keys, private keys, production data, or other secrets. Use placeholders and local environment files excluded from version control.
